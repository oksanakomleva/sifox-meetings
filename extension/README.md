# Sifox Meetings — браузерное расширение

Записывает любую встречу в браузере (звук вкладки + микрофон, смешанные) и
загружает в Sifox Meetings под вашим аккаунтом. Дальше сервер транскрибирует и
делает протокол — встреча появляется в разделе «Встречи».

## Установка (internal / unpacked)

1. Откройте `chrome://extensions`, включите **Режим разработчика**.
2. **Загрузить распакованное расширение** → выберите эту папку `extension/`.
3. Войдите в Sifox в этом же браузере (через Google) — расширение подхватит ваш
   вход автоматически (читает cookie сессии), отдельный токен не нужен.
4. В попапе расширения нажмите **«Разрешить микрофон»** (разовая выдача доступа).

## Использование

1. Откройте вкладку со встречей (Google Meet, Zoom-web, любой звонок).
2. Попап → при необходимости поправьте название → **● Начать запись**.
3. По окончании — **■ Остановить запись**. Файл загрузится, обработка идёт на сервере.

Во время записи расширение проверяет состояние аудиопроцесса. Если Chrome его
остановит, значок `REC` сменится на `!`, а попап предложит отправить уже
сохранённые части записи. Проверка выполняется локально и не обращается к
серверу.

## Как устроено

- `popup.*` — UI: токен, название, старт/стоп.
- `background.js` (service worker) — управляет жизненным циклом, получает
  `tabCapture` stream id, создаёт offscreen-документ.
- `offscreen.*` — фактический захват: tab audio + микрофон → Web Audio микс →
  `MediaRecorder` (webm/opus) → загрузка на `POST /api/extension/upload`
  с заголовком `X-Session-Token` (значение cookie вашей Sifox-сессии).

## Известные нюансы

- **Авторизация:** через ваш веб-вход в Sifox. Расширение читает cookie сессии
  (`chrome.cookies`, требует разрешение `cookies`) и шлёт её в `X-Session-Token`.
  Вышли из Sifox / сессия истекла → расширение перестанет загружать, пока не войдёте.
- **Микрофон:** кнопка «Разрешить микрофон» открывает отдельную вкладку
  (`permission.html`) и запрашивает доступ там — в попапе системный диалог
  «отменяется» (popup закрывается при потере фокуса → «Permission dismissed»).
  Разрешение сохраняется для origin расширения, и offscreen-запись использует
  его без повторного запроса. Без доступа запишется только звук вкладки.
- **Звук вкладки:** `tabCapture` глушит воспроизведение — расширение возвращает звук
  обратно, чтобы вы продолжали слышать встречу.
- **Закрытие вкладки:** если закрыть записываемую вкладку, аудио-трек вкладки
  завершается — offscreen ловит это и **автоматически останавливает запись и
  загружает** то, что успели. Закрытие всего браузера до «Стоп» теряет запись.
- **Состояние записи** хранится в `chrome.storage` (переживает усыпление service
  worker'а в MV3), поэтому кнопка «Стоп» доступна даже спустя долгое время.
- **Адрес сервера:** по умолчанию `https://sifox-meetings.up.railway.app`. Для локальной
  разработки впишите `http://localhost:8000` (и убедитесь, что он есть в `host_permissions`
  в `manifest.json`).
- **Формат:** грузится webm/opus; сервер сам конвертирует в MP3 для хранения.

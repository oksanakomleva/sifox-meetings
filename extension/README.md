# Sifox Meetings — браузерное расширение

Записывает любую встречу в браузере (звук вкладки + микрофон, смешанные) и
загружает в Sifox Meetings под вашим аккаунтом. Дальше сервер транскрибирует и
делает протокол — встреча появляется в разделе «Встречи».

## Установка (internal / unpacked)

1. Откройте `chrome://extensions`, включите **Режим разработчика**.
2. **Загрузить распакованное расширение** → выберите эту папку `extension/`.
3. В веб-приложении: раздел **«Расширение»** → создайте токен.
4. Откройте попап расширения → вставьте токен → **Сохранить и проверить**.
5. Нажмите **«Разрешить микрофон»** (разовая выдача доступа для расширения).

## Использование

1. Откройте вкладку со встречей (Google Meet, Zoom-web, любой звонок).
2. Попап → при необходимости поправьте название → **● Начать запись**.
3. По окончании — **■ Остановить запись**. Файл загрузится, обработка идёт на сервере.

## Как устроено

- `popup.*` — UI: токен, название, старт/стоп.
- `background.js` (service worker) — управляет жизненным циклом, получает
  `tabCapture` stream id, создаёт offscreen-документ.
- `offscreen.*` — фактический захват: tab audio + микрофон → Web Audio микс →
  `MediaRecorder` (webm/opus) → загрузка на `POST /api/extension/upload`.

## Известные нюансы

- **Микрофон:** доступ выдаётся для origin расширения; кнопка «Разрешить микрофон»
  в попапе делает это разово. Без него запишется только звук вкладки.
- **Звук вкладки:** `tabCapture` глушит воспроизведение — расширение возвращает звук
  обратно, чтобы вы продолжали слышать встречу.
- **Адрес сервера:** по умолчанию `https://sifox-meetings.up.railway.app`. Для локальной
  разработки впишите `http://localhost:8000` (и убедитесь, что он есть в `host_permissions`
  в `manifest.json`).
- **Формат:** грузится webm/opus; сервер сам конвертирует в MP3 для хранения.
